# 🏰 Clicker Kingdom (클릭커 킹덤)

> **클릭 한 번으로 시작되는 위대한 제국!**  
> 클릭커 킹덤은 클릭과 군대 고용을 통해 자신만의 제국을 건국하고, 10초 폭풍 연타 대전, 랭킹 경쟁, 칭호 장착, 미션 수행을 즐길 수 있는 중독성 높은 제국 성장 웹 게임입니다.

---

## 🌟 주요 특징 (Key Features)

1. **logis.xyz 스타일 랜딩 페이지 & 히어로 세션**
   - 세련된 히어로 비주얼과 기능 카드, **[⚔️ 제국 건설]** / **[🏆 랭킹 및 칭호]** 퀵 탭 제공.

2. **Spacebar Clicker 재해석 9종 군대 & 보구 상점**
   - 🗡️ 농민 창병대 ~ 🛸 차원 왜곡 요새까지 9종의 자동 생산(CPS) 군대
   - 🚩 지휘관의 영주 깃발 ~ 🌟 천상의 정복자 왕관까지 5종의 수동 클릭 multiplier 보구

3. **친구가 옆에 있을 때 바로 대전 (10초 실시간 전선 밀림 대전)**
   - 4자리 룸코드로 1초만에 대전 방 생성 및 입장.
   - 10초간 클릭 연타 속도에 맞춰 화면 중앙의 제국 전선 게이지가 상대방 제국 방향으로 실시간 밀고 밀리는 다이나믹 visual 연출!

4. **logis.xyz 스타일 다각도 리더보드 (Ranking System)**
   - 👑 누적 클릭 랭킹 / ⚔️ 제국 전투력 랭킹 / 🏆 전장 명예 랭킹
   - Top 1(🥇 금관), Top 2(🥈 은관), Top 3(🥉 동관) 뱃지 + 유저 장착 칭호 태그 및 전쟁 기록 제공.

5. **제국 칭호 & 이펙트 시스템 (Titles & Effects)**
   - 제국 등급 칭호 (*방랑 부족장* ~ *천상 패왕*) 및 특수 업적 칭호 (*백전백승의 챔피언*, *전설의 약탈자* 등)
   - 칭호 장착 시 메인 클릭 씰(Seal)의 수호 보석, 발광 및 파티클 이펙트 색상 변경!

6. **vibers 시스템 참고: 미션, 버그 제보 & 관리자 모드**
   - **일일 미션 & 업적**: 퀘스트 수행 후 포상금 획득
   - **버그 제보 & 아이디어 게시판**: 의견 작성 시 포상금(+10,000 클릭 자금) 지급
   - **제국 관리자 모드**: 치트 자금 지급(+1M / +10M / +100M), 전체 해금, 제보 관리
